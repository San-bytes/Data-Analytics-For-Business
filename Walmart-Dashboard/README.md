# Walmart Sales Performance Dashboard

An interactive Sales Performance Dashboard developed using Microsoft Power BI to analyze Walmart sales data. The dashboard provides insights into sales trends, store performance, holiday sales, and key business metrics through interactive visualizations.

---

## Project Overview

This project focuses on transforming raw Walmart sales data into an interactive dashboard that supports data-driven business decisions. The dashboard enables users to monitor overall sales performance, compare stores, analyze sales trends over time, and explore the impact of holidays on weekly sales.

---

## Problem Statement

As a Sales Analyst for a retail chain, the objective is to design an interactive dashboard that enables business users to monitor sales performance and analyze business trends through meaningful visualizations.

---

## Dataset

- **Dataset:** Walmart Sales Dataset

## Dashboard Features

- Total Sales KPI
- Average Weekly Sales KPI
- Total Stores KPI
- Holiday Weeks KPI
- Store-wise Sales Analysis
- Weekly Sales Trend
- Holiday vs Non-Holiday Sales Distribution
- Interactive Store Slicer
- Interactive Date Slicer
- Store Performance Summary Table

---

## Dashboard Preview

### Overall Dashboard

Displays the overall Walmart sales performance, including KPI cards, store-wise sales, weekly sales trends, holiday sales distribution, and summary statistics.

### Store Filter Analysis

Selecting a specific store dynamically updates all KPI cards, charts, and tables to display data for the selected store(s).

### Date Filter Analysis

Applying a date filter updates all visuals to analyze sales performance for the selected time period.

---

## Business Insights

- Walmart recorded total weekly sales of approximately **6.74 Billion**.
- The dataset contains sales records for **45 stores**.
- Sales performance varies across stores, helping identify high-performing locations.
- Holiday weeks contribute a smaller portion of overall sales compared to non-holiday weeks.
- Weekly sales fluctuate over time, with noticeable peaks during certain periods.
- Interactive filters allow users to analyze sales performance from different perspectives.
